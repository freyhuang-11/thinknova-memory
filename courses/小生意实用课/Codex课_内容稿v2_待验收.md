## 三、新页的内容

### 6 · 幻觉：AI 会一本正经地编
- **幻觉** = AI 说得有模有样，但内容是假的。
- 常见的样子：
  - 编一条不存在的法规、条款号
  - 编一个价格、日期、电话号码
  - 编一本书、一篇报道、一个网址
  - 你的文件里没有的内容，它说「文件里写了」
- 最危险的地方：**它编的时候，语气和说真话一模一样。**

### 7 · 为什么会幻觉
1. **它是在「接话」，不是在「查资料」。** 它按最像的说法一个字一个字接下去。像，不等于对。
2. **它被训练成「宁可猜，也不说不知道」。** OpenAI 2025 年的研究说，训练和考试的打分方式奖励猜答案，就像学生考试不会也要蒙一个。
3. **它根本没见过。** 冷门的事、最新的事、你公司内部的事，它都没学过，只能猜。
4. **资料太多被挤掉。** 一次塞太多，或者聊得太久，前面的内容它会漏看。

### 8 · 怎么避免幻觉
| 做法 | 怎么说 |
|---|---|
| 给它资料，只按资料答 | 「只根据这个文件夹里的资料回答」 |
| 允许它说不知道 | 写进规矩：「找不到就说不知道，不要猜」 |
| 要它标出处 | 「每个结论标出来自哪个文件、哪一段」 |
| 数字自己核对 | 重要的数字，让它再算一遍，或者用表格算 |
| 新信息让它查 | 「先联网查，再回答，附上链接」 |
| 聊太久就换 | 开一个新会话（下一页讲） |

> 讲稿：六条准则里的第 1、3 条，就是在防幻觉。

### 12 · 什么时候要开新会话
- 平时：在同一个会话里接着说就好，它会在原来的基础上改。
- 这几种情况，开一个新会话：
  1. 要做一件不相关的新事
  2. 聊得太久，它开始忘记前面的要求，或者重复做
  3. 它被带偏了，同一个错误反复出现
- 开新会话前：让它写一段**「交接摘要」**（做到哪了、定了什么、下一步是什么），贴进新会话。

### 14 · 大家都知道 Codex，它到底是什么？
- **它是一个 Agent（智能体）。**
- 聊天：你问一句，它答一句，活还是你自己干。
- Agent：你给一个目标，它自己拆步骤、动手做、检查结果，做完向你汇报。
- 讲稿：所以 Codex 不是「更会聊天的 ChatGPT」，而是「能动手的 ChatGPT」。

### 15 · Agent 怎么干活（循环图）
你派一个活 → 它想下一步 → 动手做一步 → 看结果 → 没做完？回到「想下一步」 → 做完，向你汇报

### 16 · 五个词，一次分清
| 词 | 打个比方 | 是什么 | 例子 |
|---|---|---|---|
| 大模型（LLM） | 大脑 | 会想、会说，但没有手，碰不到你的文件 | GPT、Claude、DeepSeek |
| 工具（Tools） | 手 | 读写文件、搜索网页、发邮件、打开网页 | Codex 里的文件、浏览器、Gmail 插件 |
| 技能（Skills） | 岗位手册 | 教它某一类活怎么干，用到才翻开 | 「做周报」技能 |
| Harness | 工作台 | 把大脑接上手：管权限、规矩、记忆，让它一圈一圈地干 | Codex 这个软件本身 |
| Agent | 能干活的员工 | 大模型 + Harness + 工具，再配上技能 | Codex、WorkBuddy、小龙虾 |

> 讲稿：插件（Plugins）= 别人打包好的「工具 + 技能」，装上就能用。

### 17 · 一句话记住
**同一个大脑，装进聊天窗口是「顾问」，装进 Codex 是「员工」。**

### 18 · 外面工具这么多：一张地图
| 类型 | 代表 | 适合做什么 |
|---|---|---|
| 聊天助手 | ChatGPT 聊天、Claude、豆包、DeepSeek | 问答、写东西 |
| 个人生活 Agent | Meta Muse、Grok | 在手机上帮你订、买、发消息（Muse 目前只在美国、加拿大） |
| **办公 Agent（今天学的）** | **Codex**、WorkBuddy（腾讯）、Claude Cowork | 处理你电脑里的文件、邮件、报告 |
| 编程工具 | Cursor、Trae（字节）、Claude Code | 写代码、做软件 |
| 开源、自己养 | OpenClaw「小龙虾」 | 懂技术、爱折腾的人用；权限大，风险也大 |

> 讲稿：不教下载安装，大家多半已经有了。重点是知道每一类是干什么的。

### 19 · 怎么选：问自己四个问题
1. **我的活在哪里？** 手机上、电脑文件里，还是代码里？
2. **资料能不能出公司？** 客户资料要看隐私规定（PDPA）。
3. **公司允许用什么？要不要付费？**
4. **我已经在用哪一家？** 账号、记忆、资料都在那。
- 结论：**学方法，不押工具。** 规矩文件、技能大多能搬家。比如设置里有「导入」，能把别的工具里的技能搬过来。

### 20 · ChatGPT 里的几种用法
桌面应用左上角切换两边，「ChatGPT」那边顶部再切「聊天 / 工作」：

| 在哪 | 界面上写的 | 什么时候用 |
|---|---|---|
| ChatGPT → 聊天 | 创建、学习和探索 | 问答、写东西、快速分析 |
| ChatGPT → 工作 | 「使用 ChatGPT Work」；下面可以选项目、文件、插件 | 交给它一件要花时间的活，交回成品：报告、表格、PPT |
| **Codex（今天用）** | 构建、调试和发布 | 选一个文件夹，在你电脑上动手：整理文件、搭工具、定时跑 |

- 另外几种形式：
  - **项目**：一组对话、资料和专属指令放在一起
  - **临时对话**：不进记忆
  - **群聊**、**语音**、**深度研究**
- 输入框下面要看两样：
  - **权限**：点它选三档之一（下一页之后讲）。
  - **模型和思考力度**：例如「GPT-6 Luna 中」，难的活把力度调高。
- 讲稿：三种用法底下是同一个 Agent，区别在交出来的东西。今天六个自动流都用 Codex。

### 21 · 手机上接着用电脑上的 Codex
1. 手机 ChatGPT 里进入「Codex」
2. 右上角「⋮」→「添加连接」，按提示和电脑配对（同一个账号）
3. 顶部可以在「全部」「Cloud」和你的电脑之间切换；项目列表和电脑上一样
4. 手机上可以：发新任务、回答它的问题、批准操作、看结果
- 条件：**电脑要开着、联网、不休眠。**
- 电脑关了还想让它跑：用 Codex Cloud。它在 OpenAI 的电脑上跑，碰不到你电脑里的文件。
- 【讲前核对：电脑那边配对的步骤；这是预览功能，入口可能会变】

### 22 · 选文件夹和权限（改）
点输入框左下的权限，弹出「应如何批准 ChatGPT 操作？」：

| 权限 | 界面上的说明 | 课上用不用 |
|---|---|---|
| 请求批准 | 编辑外部文件和使用互联网时始终询问 | **课上用这个** |
| 帮我批准 | 仅对检测到的风险操作请求批准 | 熟练以后再用 |
| 完全访问权限 | 可不受限制地访问互联网和你电脑上的任何文件 | 不要用 |

- 先复制一份文件夹，让它在复制的文件夹里干活。
- 安全规则那页同步改：「永远不选 Full Access」→「不要选『完全访问权限』」。

### 24 · 学会新技能、找对工具
1. **先看现成的**：左边「插件」页，分「插件」和「技能」两栏。插件有「公开 / 个人」，热门的有 Gmail、Google Drive、Outlook、Notion；右上角「添加」
2. **没有就让它自己写**：一个流程做顺了，对它说「把刚才的做法整理成一个技能」
3. **别人写好的技能**：只装来源可信的；装之前让 Codex 先读一遍，讲给你听它会做什么
4. **用过别的工具**：设置 →「导入」，把别的工具里的技能搬过来

### 25 · 练习（改）
1. 打开 Codex，选「AI 练习」文件夹
2. 把六条准则贴进：设置 → 个性化 → 自定义指令 →「Codex 指令」（它会存成 AGENTS.md）
3. 问它：「这个文件夹里有什么？你能帮我做哪些事？」
4. 让它整理一个文件，然后说：「把刚才的做法整理成一个技能」
5. 看它的回答有没有先问你问题

### 27 · 让它用你电脑上的软件（电脑操控）
- 位置：设置 →「电脑操控」（「管理 ChatGPT 如何使用你电脑上的其他应用程序」）
- 能接上的，例如：
  - **Google Chrome**：要装浏览器扩展，之后它能帮你在网页上操作
  - **Microsoft Edge**：同上，要先装扩展
  - **Microsoft Excel**：打开开关，它通过 Excel 加载项直接改表格
- 「始终允许的应用」先留空，让它每次用之前都问你
- 讲稿：这一页接到客户档案、业务报告两个练习，那两个都会用到 Excel。
- 设置里同一组还有「浏览器」「云电脑」两项【讲前核对：这两项是做什么的】

### 搭小工具 · 为什么第一次搭出来的不好用
- 只说一句「做个报价工具」，它只能猜
- 一次要太多功能
- 没说谁用、在电脑还是手机上用
- 没让它先出方案，直接开写
- 做完不试就用

### 搭小工具 · 照着这个模板说（可以照抄改）
```
帮我做一个网页小工具：【工具名】。
谁用：【我 / 店员】，在【电脑 / 手机】上用。
它要做：输入【什么】，得到【什么】。

要求：
1. 只做一个 .html 文件，双击就能打开，不用安装任何东西
2. 不用 React 这类框架，所有代码写在这一个文件里
3. 中文界面，字和按钮要大，手机上也能用
4. 填过的内容存在浏览器里，刷新不丢
5. 结果可以一键复制

先别写代码：先列出你打算做的功能和页面样子，等我确认再做。
```
> 讲稿：最后一句最重要。先出方案、你点头再做，比做完再改省很多事。

### 搭小工具 · 做完试这几下
- 乱填、不填，会不会出错？
- 用手机打开，看不看得清？
- 刷新一下，数据还在不在？
- 拿一个你算过的例子，结果对不对？

### 练习（改）：用模板做一个报价计算器
1. 打开 Codex，新建「报价工具」文件夹
2. 照模板填：输入数量、单价、折扣，得到总价
3. 看它的方案，满意了说「可以，开始做」
4. 双击打开网页，按上一页试四下
5. 哪里不好，直接告诉它改
