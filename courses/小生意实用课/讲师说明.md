## 结构
| 页 | 部分 |
|---|---|
| 1–9 | 认识 AI：大部分人只用来聊天；AI 带来的四个阶段；AI 能做的六类事；4 个脾气；**AI 的边界**；说话四要素；两种说法；不满意就接着改 |
| 10–16 | 装好 Codex：Codex 是什么；安装登录；文件夹和权限；**定规矩（六条准则，唯一可以直接复制的内容）**；练习；连 Gmail、日历、Drive；安全规则 |

| 50–51 | 回去第一周；答疑 |

## 讲前在真机核对（资料来自官网摘要，官网当时打不开）
| 课件里写的 | 核对什么 |
|---|---|
| Codex 在新版 ChatGPT 桌面应用里，切到「Codex」模式 | 你们装的版本里，模式名是否一致 |
| Windows 在 Microsoft Store 安装 | 认准发布者是 OpenAI（网上有同名山寨软件） |
| 免费账号也能用，但有用量限制 | 学员用什么版本上课；用量够不够做完所有练习 |
| 权限三档：Read Only / Default / Full Access | 界面上的名字 |
| 设置 → 个性化 → 自定义指令 | 中文界面的菜单名 |
| 左边栏「Plugins」「Automations」「Triage」 | 位置和名字；Gmail 插件对你们的版本是否可用 |
| 定时任务要电脑开着、App 开着才会跑，错过的不补跑 | 课件已写明，讲的时候强调 |
| 设置 → Data controls 关掉训练 | 中文界面的菜单名 |

## 课前要准备
- **示范数据**：示范邮件（给不想用自己邮箱的学员）、示范订单表（客户分析练习）、3 份示范资料（知识库练习）。课件和讲稿里都写了「用助教给的示范数据」。
- 助教人数：要按装软件、连插件这两步最容易卡住来配。

## 企业案例的去敏处理
案例取自一份培训管理系统的需求清单。已删掉客户名、日期和保密标记；会计系统、政府补贴申报、国家身份登录都改成了通用说法，没有出现具体供应商和系统的名字。
