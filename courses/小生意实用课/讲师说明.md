## 事实依据与讲前核对

工具功能按 OpenAI 和 Anthropic 官方帮助中心核对（2026-10-13）。OpenAI 帮助中心当时打不开，只看了搜索摘要，所以 ChatGPT 的部分**讲前请在实际界面上再核对一遍**：

| 课件里写的 | 讲前核对什么 |
|---|---|
| ChatGPT 连 Gmail、日历在「设置 → Plugins（也可能叫 Apps）」 | 这个菜单 2025 年底到 2026 年改过两次名，看你账号里实际叫什么 |
| 连 Gmail、日历需要 Plus 或以上 | 免费版能不能连，官方没有写明 |
| 新加坡账号能用 Gmail、日历连接 | 官方没有单独写新加坡，实测一下 |
| ChatGPT 能直接往日历里加日程 | **课件没有这样写**（个人版官方未确认），只写「确认后把安排放进日历」 |
| 定时任务在左边栏「Scheduled」；免费版每天最多一次、时间不精确 | 电脑客户端可能看不到这个入口，用网页版 |
| 自定义指令在「设置 → 个性化 → 自定义指令」 | 中文界面的菜单名 |
| 关闭训练在「设置 → Data controls」 | 中文界面的菜单名 |
| Claude 免费版能连 Gmail 和日历，免费版最多 5 个项目 | 已读官方页面确认 |

## 讲课要点
- 第 7 页那六条规矩，是学员**唯一**可以直接复制的内容。其他页只教方法（跟 AI 说清楚哪几点），不给整句模板。
- 第 13 页隐私一定要讲：ChatGPT 默认会用对话训练模型；客户资料传给 AI，等于把资料传到海外（新加坡 PDPA 的跨境传输规定）。
- 企业自动化工作流只讲「这部分要专业团队」，结尾一句「我们提供 AI 解决方案」，不展开报价。
