# AI 实战课程：Claude Code × Codex × ThinkNova AI 视频生成

> 版本：2026-10-07 ｜ 对象：团队成员、合作伙伴、想系统掌握 AI 编程助手和 AI 内容生产的人

## 课程目标

学完能够：
1. 讲清 AI（大模型 / Agent）是怎么工作的，出错时知道往哪一层查
2. 准确使用行业术语：Skills、Agent、Sub-agent、Harness、MCP、RAG、Memory、Hooks、Workflow
3. 熟练使用 Claude Code 和 Codex，包括规则文件、权限、技能、子 agent、自动化
4. 用记忆和规则把 AI 管住：让它每次都按规矩来
5. 把一件业务拆成可落地、可验收的 AI 工作流
6. 理解 ThinkNova 的 AI 漫剧 / 短视频生成管线和它踩过的坑

## 一页纸总结

1. **模型无状态**，一切「聪明」来自上下文——上下文工程比换模型更重要。
2. **Harness 是模型的身体和制度**：Claude Code、Codex 都是 Harness。
3. **能用 Workflow 就别用 Agent**；最贵的步骤前加关卡。
4. **规则分四层**：对话 < 规则文件 < Skill < 权限 / Hook。事故级规则必须落到最后一层。
5. **规则要短、要指派式、不能打架**；记忆只留现状、旧结论当场删。
6. **验收只认最终产物**，落库 ≠ 送达，单帧 ≠ 全片。
7. **多个模型报同一个错 = 提示词问题。**
