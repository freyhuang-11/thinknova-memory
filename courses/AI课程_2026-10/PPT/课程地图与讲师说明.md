## 讲师要先吃透的一页：模型、Harness、Agent

| 词 | 像什么 | 真实产品 |
|---|---|---|
| 模型 | 大脑：会思考、会说话，但没有手脚 | Claude、GPT、DeepSeek |
| Harness | 身体 + 规矩：让大脑能动手用工具，同时限制它不乱来 | Claude Code、Codex 这套软件 |
| Agent | 能干活的员工：大脑装进身体、接到任务、自己一步步做完 | 你让 Claude Code 整理文件时，正在干活的它 |

- 公式：**Agent = 模型 + Harness**
- 开车比喻：司机的脑子 = 模型；汽车和交规 = Harness；把你送到目的地的整趟服务 = Agent。只有司机没有车，就只能告诉你路怎么走，这就是普通的聊天 AI。
- 学员问「Claude Code 到底是 Agent 还是 Harness」：严格说它是 Harness（那套软件），装上 Claude 大脑、接到你的任务跑起来，就是一个 Agent。日常说它是 AI Agent 也不算错。
- 为什么要分清：AI 干得好不好，一半看大脑，一半看装备和规矩。员工手册、权限、技能包、记忆都属于 Harness 这一边，是我们自己能调整的。
