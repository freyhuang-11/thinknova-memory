# 第 7 课 · 实战：ThinkNova 的 AI 漫剧 / 短视频生成管线

> 目标：理解一条「文字 → 剧本 → 分镜 → 画面 → 视频 → 配音」的 AI 生成管线是怎么搭的，每一层管什么、最容易在哪里出错。
> AI 漫剧、AI 短剧、AI 广告片的底层结构相同，本课以 ThinkNova（给实体店老板用的海报 / 短视频 SaaS）为例。
> ⚠️ 本课里出现的数值都是历史快照，用于说明原理；实际上限一律以线上 config 为准。

---

## 7.1 AI 漫剧的通用生产链

```
① 故事/资料输入 ─► ② 编剧（LLM）─► ③ 角色与场景设定（参考图）
                                         │
  ⑦ 后期合成 ◄─ ⑥ 配音 TTS / 口型 ◄─ ⑤ 图生视频 i2v ◄─ ④ 分镜图 t2i / i2i
  （剪辑·字幕·BGM）
```

| 环节 | 用的模型 | 产出 | 行业术语 |
|---|---|---|---|
| ② 编剧 | 文本大模型 | 分镜脚本：每格画面 + 台词 + 情绪/镜头标注 | Script / Shot list |
| ③ 设定 | 人工上传或生图 | 人物、产品、场景参考图 | Reference / Character sheet |
| ④ 分镜 | 文生图 t2i / 图生图 i2i | 分镜板（多宫格）或逐镜头分镜图 | Storyboard |
| ⑤ 视频 | 图生视频 i2v | 每个镜头的视频片段 | Image-to-Video |
| ⑥ 声音 | TTS / 声音克隆 / 口型同步 | 配音、对白 | Voice / Lip-sync |
| ⑦ 后期 | 程序拼接 | 成片 | Compositing |

**AI 漫剧最大的技术难题 = 一致性**：同一个角色在 10 个镜头里长得一样、同一个产品形态不变、场景不穿帮。解法几乎全靠**参考图**，而不是靠文字描述。

## 7.2 ThinkNova 的两条视频管线

### 管线 A：短视频 Agent（一键出片，Workflow 模式）

```
1 商家填资料（商品名/卖点/活动/风格…）
2 上传参考图（人物 / 场景 / 产品，可选）
3 编剧（LLM）：生成每格画面 + 台词
4 生图：生成多宫格分镜板（有参考图走图生图，无则文生图）
5 裁格：从分镜板裁出第一格作为首帧
6 图生视频：首帧 + 分镜板 + 参考图 → 视频（人声由视频模型直接生成）
```

### 管线 B：视频工作台（长视频自动拼接，人机协作模式）

```
资料 → 编剧出镜头时间轴 → 逐镜头生成分镜图【人工审核】
     → 逐镜头生成视频【人工审核】→ TTS 配音 + 字幕 + 硬切合成
```

- **核心卖点：先审后花钱；哪段不满意只重做那一段。**
- 编剧逐镜头输出情绪标签，TTS 按情绪参数配音。
- 默认是后期配音（画外音），**不做口型同步** → 画面里就不要安排正脸说话的镜头。

**两条线完全隔离**：页面、配置、任务、案例库都不共用。一条线的实测结论不许外推到另一条。

> 📌 对照第 6 课：管线 A 是纯「提示链」；管线 B 在最贵的步骤前加了**人工关卡**，是「提示链 + 人审」。

## 7.3 三层职责分工（最重要的设计原则）

| 层 | 只管 | 不管 |
|---|---|---|
| **编剧** | **演什么**：每格画面、台词、灯光/情绪/镜头标注 | 不写产品外形（它看不到参考图，写了生图就照文字画错） |
| **生图** | **画得对且真**：主体、真实感、负面词 | 不写死画面内容，**不画任何字** |
| **图生视频** | **怎么动 + 怎么念**：画面推进、肤质、口播情绪、灯光延续；参考图三锁（人物·产品·场景） | 不改剧情 |

核心思路：**生图和视频层只给「护栏和风格」，具体画面和台词全交给编剧** —— 既避免层与层之间指令冲突，又保住每条片的多样性。

---

## 7.4 两条铁律

1. **每段提示词自包含**：编剧、生图、视频每次调用都无状态，只拿到「本段文字 + 本次传入的图」。不许写「参考上文」「按后台配置」。
2. **视频画面零字幕**：台词只念、不画进画面。字一旦画进分镜图，就会被裁进首帧、再进视频，严重降质。（海报不受此限——海报本来就要标题和价格。）

---

## 7.5 编剧层：内容质量的源头

**编剧 = 营销专家**（老板定调）：每次写台词和画面，都要站在观众角度想「看到这个画面、听到这句话是什么感受」。

### 片型三档（先定档，再写）

| 档 | 判断标准 | 结构 | 场景举例 |
|---|---|---|---|
| **A 故事档** | 观众还没打算买；有一个能被推翻的看法（太贵/不需要/不靠谱） | 冲突 → 加码 → 揭晓 → 转变 → 收梗；商品是谜底 | 优惠、顾客评价、前后对比、广告大片 |
| **B 叙事档** | 有人物有情绪，但不搞冲突 | 一件事讲清楚 + 一个动作作证 | 新品、招牌、制作过程、门店、老板出镜 |
| **C 直给档** | 观众已想买，只差信息 | 信息优先，不铺情绪 | 价目表、通知 |

### 台词规则（节选）
- 句数 = 镜头数，句句完整、标点收尾。
- 不许复读、不许句句同构排比；至少一半句子说**具体事实**。
- **商品名一字不差**。
- **画面要为台词的主张作证**：台词说「好用」，画面必须出现使用的动作；台词否定的动作不许拍。

### 用户补充要求优先级最高
商家写「开场先给门店招牌全景」，编剧第 1 格就照做。但文字只能控制「拍什么」，**锁不住「是哪一家店」**——那要靠参考图。

## 7.6 一致性：参考图三锁

| 锁 | 锁什么 | 怎么做 |
|---|---|---|
| 人物锁 | 同一张脸、同一身衣服 | 人物参考图进生图和视频两层 |
| 产品锁 | 产品形态、包装 | 产品参考图；编剧**禁写形态词** |
| 场景锁 | 门店环境 | 场景参考图 |

规则举例：有产品参考图时，商品特写不少于两格；没有人物参考图时，不做双人对手戏；达人带货类必须有人物参考图（否则是「假人在推荐」）。

**多参考图实战经验**：多张参考图同时喂给视频模型时，模型可能用背景音乐把音轨填满、人声消失。有效解法是在提示词最前面明确写「不要背景音乐，只要人物讲话声音」——管的是**音轨内容分配**；而写「禁止静音」完全无效。

## 7.7 「零动脑」产品原则

客户是不懂提示词的线下小店老板。ThinkNova 的唯一优势（除了便宜）= **客户不用动脑就做出他要的东西**：

- 每个「行业 × 场景 × 案例」组合的按钮（出镜方式 / 风格 / 结尾行动号召 / 卖点 / 画面重点 / 节奏）**全部预设好**。
- 客户选个场景 + 案例 → 点生成 → 就是他脑子里想的画面 = 成功。
- 需要客户自己琢磨调按钮 = 失败。

> 这也是所有 AI 产品的通用原则：**把提示词工程藏在产品里，不要甩给用户。**

## 7.8 踩坑实录（每一条都是真实事故）

| 现象 | 真正原因 | 教训 |
|---|---|---|
| 换了 6 个模型，10 次全报同一类错 | 提示词里 7 处默认「多镜头」，案例却设了 1 个镜头，指令自相矛盾 | **多个模型报同一个错 = 提示词问题**；从案例层解决，不和全局规则硬拼 |
| 加了一句「兜底说明」不起作用 | 一句话压不住七处相反指令 | 别指望加一句话对抗多处冲突，要找到冲突源 |
| 一天加了 3 处规则，编剧层全挂 | 提示词超出模型的字节上限 | 改前改后都量字节；**只减不增**；上限各模型不同，逐个问 |
| 一半订单要重试 | 系统贴着上限跑（中位数占上限 85%），规则里「写满」和「不超过」打架 | 给上限留余量；删掉模型不读的元数据（一度占 25% 预算） |
| 「台词差、情绪平」 | 一半稿子是重试到最后、由最弱的备用模型写的 | 评价提示词效果前，先看这单是第几次尝试、哪个模型出的 |
| 配置改了「没生效」 | 写进的字段根本不进最终提交串；或两个镜像字段只写了一个被静默回滚 | **落库 ≠ 送达**：必须烧一单，拉真实提交串看到新文案才算 |
| 报「全程无人物」，其实前 6 秒全是人脸 | 只看了一帧截图 | 视频验收必须逐帧：2fps 抽帧拼联系表通看 |
| 负面词写了「绝不出现 X」反复无效 | 禁令式规则模型不执行 | 改成指派式：「第 N 格拍 Y」 |
| 产品被画成整只，实际是切块 | 编剧写了形态词，生图照文字画 | 形态交给参考图，编剧禁写形态 |

## 7.9 用 Claude Code 运营这条管线（我们的日常）

我们自己就是用 Claude Code 做 ThinkNova 的运营和提示词工程的：

| 工作 | 怎么用 AI |
|---|---|
| 改提示词 | 先读现状源（记忆 → 技术文档 → 线上 config），量字节，查冲突，改一处 → 烧一单验证 |
| 排查失败订单 | 拉该单每次尝试的原始报错，分模型统计，判断是提示词还是供应商问题 |
| 成片验收 | 让 AI 用 ffmpeg 抽帧拼图、whisper 转写台词，逐帧比对 |
| 批量改案例 | 写一段脚本一次干完，只回摘要（节省上下文）；先单条验证再铺开 |
| 写营销内容 | 走 skill：短视频四件套（台词风格 → 前 3 秒钩子 → 节奏 → 分镜提示词）、小红书四柱 |
| 跨会话协作 | 记忆库（本仓库）+ 交接档；派活给另一条线的会话只给「主题/受众/约束」，不教怎么做 |

## 7.10 本课小结

1. AI 漫剧 = 编剧 → 设定 → 分镜 → 视频 → 声音 → 后期，**一致性靠参考图**。
2. 三层职责分工 + 每段提示词自包含 + 视频零字幕。
3. 内容质量的源头在编剧层：先定片型，画面为台词作证。
4. 大部分「模型不行」其实是「提示词互相打架」或「超上限」。
5. 验收只认最终产物，逐帧看。

**课后练习**：选一个你熟悉的商品，按「A 故事档」写一份 5 格分镜脚本（每格：画面 + 台词 + 情绪），并检查：画面有没有为台词作证？有没有写产品形态词？
